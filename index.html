Beginner Tech Guide

Choose your first technology track

✦ Artificial Intelligence

What it is: Tools that can learn patterns and help solve problems.

Why it matters: AI is shaping products, research, and workplace workflows.

What you can do: Try prompt exercises, learn responsible AI, and use AI tools for study.

First step: Explore a beginner AI activity and compare outputs.

☁ Cloud

What it is: Cloud computing gives teams flexible access to services and storage.

Why it matters: Cloud powers websites, apps, data pipelines, and software services.

What you can do: Deploy a project and understand storage, APIs, and serverless ideas.

First step: Try a basic cloud deployment and learn the core terminology.

⌘ Web Development

What it is: Web development builds websites and web apps that people use online.

Why it matters: It helps you turn ideas into accessible digital experiences.

What you can do: Build static pages, forms, landing pages, and portfolio projects.

First step: Create a personal homepage or event page.

Σ Data Science

What it is: Data science turns information into patterns and decisions.

Why it matters: It helps teams understand performance, user behavior, and trends.

What you can do: Explore spreadsheets, charts, and simple datasets.

First step: Analyze a dataset and create a simple chart.

✎ Firebase

What it is: Firebase is a platform for app development services and quick launch tools.

Why it matters: It helps teams build apps faster with authentication, storage, and database services.

What you can do: Create a project, add a database, and connect a form.

First step: Create a Firebase project and connect a static page.
